# StockTrend-Analyzer-
A complete Time Series Forecasting project using ARIMA, SARIMA, and Prophet to predict stock market prices. Includes model comparison, data visualization, and a live Streamlit dashboard for future trend prediction.


📌 Project Overview

This project performs end-to-end stock price forecasting using four powerful time series models — ARIMA, SARIMA, Prophet. The objective is to analyze market trends, train predictive models, visualize future price movement, and provide a comparison of classical statistical methods vs neural-network-based forecasting.

The project is developed with the goal of producing accurate future predictions, dynamic model visualization, and a clean deployable Streamlit dashboard, making it professional, scalable, and ideal for real-world financial forecasting.

🚀 Key Features

✔ Real-time stock dataset input via CSV
✔ Interactive forecasting dashboard using Streamlit
✔ Trend, seasonality & future prediction visualization
✔ Classical + Deep Learning comparison in one interface
✔ 30-Day future stock price forecasting
✔ Full data preprocessing, scaling & model evaluation

🔬 Models Implemented
1️⃣ ARIMA

Suitable for non-seasonal time series

Captures linear trends and short-term dependencies


2️⃣ SARIMA

Seasonal extension of ARIMA

Models periodic/seasonal behavior in stock data

3️⃣ Prophet

Trend + seasonality forecasting by Meta

Extremely robust for business time-series
